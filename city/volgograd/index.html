Волгоград: требования и реестр

Раздел реестра CertStatus по теме: органы по сертификации и лаборатории: Волгоград.

Что нужно знать

Аккредитация даёт организации право работать только в пределах её области. Действующая аккредитация по данным реестра на дату сверки у 62 из 233.

Где закреплено

Записи об аккредитации ведёт Росаккредитация во ФГИС. Юридическую силу имеет именно эта запись.

Кто ведёт реестр

Записи об аккредитации ведёт Росаккредитация во ФГИС. Справочник показывает их по данным реестра на дату сверки.

Где закреплены сведения об организациях

Сведения об аккредитованных лицах Волгоград хранятся во ФГИС Росаккредитации. Справочник показывает их по данным реестра на дату сверки, юридическую силу имеет запись в государственной системе.

Какие бывают организации

В регионе работают органы по сертификации продукции, испытательные лаборатории, органы инспекции и другие аккредитованные лица. У каждого типа своя роль: одни выдают сертификаты, другие проводят испытания.

Требования к аккредитации

Аккредитацию дают в национальной системе аккредитации по закону об аккредитации. Организация обязана соответствовать критериям и периодически подтверждать компетентность.

Что закреплено в записи

Запись организации из Волгоград хранит наименование, адрес места деятельности, номер аттестата, статус и область. Изменения вносятся решениями с датой, поэтому по записи видно не только текущее состояние, но и историю.
